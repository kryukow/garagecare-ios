# GarageCare / «Мой гараж»

- Актуальная основа приложения — `main`. Не начинайте изменения от старых `feature/*`, `fix/*` или `release/*` и не подменяйте актуальные файлы отдельными файлами из старой версии.
- Версия приложения и номер сборки задаются в `project.yml`. Текущая версия — 1.4.3 (10), основа — полная 1.4.1 (7), коммит `7b46a3376fd6ab9a1ddf1ca56dcb13892c23cb68`.
- Сохраняйте возможности 1.4.1: LPG/CNG, сортировку регламента, редактирование истории, PDF, JSON-восстановление, запчасти и фото чеков.
- Основной интервал работы — километры от последнего выполнения. Моточасы — явно включаемое дополнительное условие; календарный срок показывается только для HU/TÜV и ранее созданных календарных работ. Все числовые поля должны иметь постоянные подписи и единицы измерения.
- Фото выполненной работы и чек хранятся отдельно. Изменения вложений должны учитываться в истории, редактировании, JSON-копиях, восстановлении и PDF. Старые копии без новых необязательных полей должны читаться.
- Сохраняйте Bundle ID `io.garagecare.app` и совместимость с данными установленной версии. Не добавляйте сертификаты, профили подписи, ключи или личные данные в репозиторий.
- `build-ipa.yml` обязательно проверяет unit-тесты и затем собирает IPA; UI-тесты — дополнительный ручной запуск из того же Action после загрузки IPA. Проверяйте фактические CFBundleShortVersionString/CFBundleVersion и SHA исходников артефакта. Успешная упаковка не подтверждает работу на физическом iPhone.
- Для следующих исправлений используйте одну текущую линию разработки. Не создавайте новых веток или PR без отдельного запроса пользователя: обновления напрямую в `main` с ростом версии/build. Не оставляйте конкурирующие «актуальные» версии.

- Для HU/TÜV и страховки используются отдельные даты каждого автомобиля. Не создавайте фиктивные сроки, не считайте банковские списания подтверждёнными автоматически.
- Фотографии сохраняются с первым изображением в исходном поле и дополнительными в отдельном optional-поле; JSON и PDF должны хранить все снимки.
