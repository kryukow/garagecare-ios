# Мой гараж (GarageCare)

Нативное приложение для iPhone: автомобили, пробег, моточасы, регламентные работы, история обслуживания, заправки и расходы. Данные хранятся локально; вход, подписка, сервер и App Store не нужны.

## Единственная актуальная версия

**Главная ветка — `main`.** Версия и номер сборки определяются исключительно параметрами `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` в [`project.yml`](project.yml). Не используй старые ссылки на IPA, если их версия не совпадает с `project.yml`.

**Текущая версия: 1.5.0, build 20.** Изменения собраны в одном [CHANGELOG.md](CHANGELOG.md).

Реализовано:
- несколько автомобилей с фотографиями, пробегом и необязательными моточасами;
- регламент в километрах, дополнительные условия в моточасах; календарные интервалы — для HU/TÜV и ранее сохранённых календарных работ;
- сроки HU/TÜV и ожидаемые страховые платежи по каждому автомобилю;
- выполненные работы, запчасти, отдельные фотографии работы и чеков, галерея;
- заправки с бензином/дизелем/LPG/CNG/E85, статистикой расхода и расходами по валютам;
- ручная сортировка работ и редактирование записей;
- JSON-резервная копия/восстановление (совместимость старых версий), CSV и PDF-экспорт;
- локальные уведомления, светлая/тёмная темы и графитовая навигация.

Пустые показания моточасов не должны показываться как необъяснимое `0.0`. Во всех формах клавиатуру можно скрыть прокруткой или кнопкой «Готово».

## Сборка и скачивание

Единственный workflow: [**Собрать IPA**](https://github.com/kryukow/garagecare-ios/actions/workflows/build-ipa.yml).

После изменения `main` автоматически выполняются unit-тесты на Xcode 27, затем собирается **неподписанная IPA**. В успешном запуске внизу раздела **Artifacts** находится файл вида `GarageCare-1.5.0-build20-unsigned.ipa` и `BUILD-INFO.txt` с SHA и номером версии. Ручной запуск того же workflow доступен кнопкой **Run workflow**; Проверка графитового интерфейса выполняется автоматически; полный набор UI-тестов включается отдельной опцией.

**Неподписанную IPA нельзя установить на обычный iPhone без подписи.** Для обновления установленного приложения сохраняй прежний Bundle ID `io.garagecare.app` и совместимый профиль подписи. Перед установкой новой версии экспортируй JSON-копию в «Файлы» и убедись, что файл сохранён. Не удаляй старую версию до проверки данных.

Для локальной проверки исходников на Mac:

```bash
brew install xcodegen
xcodegen generate
xcodebuild build -project GarageCare.xcodeproj -scheme GarageCare \
  -destination "generic/platform=iOS Simulator" \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
```

## Порядок разработки

**Новая идея → одна законченная правка в `main` → повышение версии/build → успешные тесты → новый IPA-артефакт.** Без конкурирующих рабочих веток, черновых PR и параллельных «актуальных» версий. Исторические коммиты Git — обычная история изменений, а не другие версии приложения.

Не добавляй в GitHub сертификаты, provisioning profiles, API-ключи, личные данные и подписанные сборки. Исходники и unsigned-сборка публичные, пользовательская база — только на устройстве.


### Иконки обслуживания
В регламентах используются 33 оригинальных контурных символа деталей. По умолчанию символ определяется по названию работы (русский, немецкий, английский), его можно изменить вручную или вернуть автоподбор. Галерея позволяет проверить весь набор без изменения записей. Все исторические ключи остаются совместимыми со SwiftData и JSON-копиями.


### Графитовое оформление 1.5.0

«Тихая дорога» и иконка «Ночной маршрут». Выбирайте автомобиль в заголовке; паспорт и полный регламент доступны справа. Контроль сроков раскрывается нажатием, пробег редактируется в его блоке. Анимация останавливается в фоне, поддерживает уменьшение движения и ручную паузу. Галерея 33 иконок доступна снизу главного экрана и в настройках; она не изменяет сохранённые работы. Ручной символ каждой работы меняется в её редакторе.
