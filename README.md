# Мой гараж — GarageCare

Нативное iOS-приложение для локального учёта автомобилей, пробега, регламентных работ, истории обслуживания и заправок.

## Актуальная версия: 1.4.2 (8)

Единственный источник актуального приложения — `main`. Версия и номер сборки задаются в `project.yml`.
Основа 1.4.2 — полная версия 1.4.1 (7) из коммита `7b46a33`, с сохранением LPG/CNG, сортировки, PDF, редактирования истории и JSON-восстановления.

- Основной интервал новой работы — «Каждые, км»: например, 10000 после 100000 км означает следующую работу на 110000 км. После выполнения начинается новый отсчёт.
- Моточасы и календарный срок включаются отдельно. Пустые необязательные поля имеют постоянные подписи вместо непонятного 0.0.
- Фото выполненной работы и фото чека добавляются отдельно, видны в истории, редактируются, сохраняются в JSON и PDF. Старые копии без фото работы по-прежнему читаются.
- Одна автоматическая сборка `build-ipa.yml` запускает unit/UI-тесты и лишь после их успеха упаковывает IPA. Артефакт содержит версию в имени; результаты тестов содержат снимки экранов.

Ветки `feature/garagecare-1-4-public`, `fix/motohours-fields`, `fix/engine-hours-ui` и `release/garagecare-1.4.2-build8` — исторические. После объединения ссылки веток убраны из активного списка. Их нельзя использовать как основу следующего обновления. Исходные коммиты сохранены в истории `main` и локальной копии `GarageCare-before-1.4.2.bundle`; разработка и сборка последующих версий ведутся от `main`.

Для обновления поверх 1.4.1 подпиши IPA тем же сертификатом и с прежним Bundle ID `io.garagecare.app`. Перед установкой сохрани JSON-копию через настройки приложения. Проверка в симуляторе не заменяет проверку на личном iPhone.

## Сборка

Проект генерируется через XcodeGen и проверяется в GitHub Actions на Xcode 27.

```bash
brew install xcodegen
xcodegen generate
xcodebuild build \
  -project GarageCare.xcodeproj \
  -scheme GarageCare \
  -configuration Debug \
  -destination "generic/platform=iOS Simulator" \
  CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO
```

Для CI не нужны сертификаты, provisioning profiles, API-ключи или другие секреты.

## Данные

Приложение local-first: основная база хранится на устройстве через SwiftData. Поддерживаются JSON backup/restore и CSV-экспорт истории.

## Privacy

Репозиторий не содержит signing credentials, provisioning profiles, API keys или пользовательских данных.

## История 1.4.0

Новые возможности: отдельные виды топлива (бензин, дизель, LPG, CNG, E85), моточасы для автомобиля и регламента, HU/TÜV, редактирование истории ремонта и заправок, артикулы запчастей, фото чеков, PDF-экспорт, JSON backup v3 с чтением копий 1.3.0 (v1/v2).

**Перед обновлением** обязательно создай JSON-резервную копию из установленной версии 1.3.0 и проверь её наличие в приложении «Файлы». Не удаляй рабочую версию, пока данные не проверены в новой. В 1.4.0 прежние заправки из JSON v1/v2 получают тип «Бензин»; при необходимости вручную исправь записи LPG.

Используется прежний Bundle ID публичного проекта `io.garagecare.app`, без изменения схемы подписи. Если установленная на устройстве версия 1.3.0 использует другой Bundle ID, iOS установит версию 1.4.0 отдельно, а перенос выполняется через JSON.

Для проверки создаётся неподписанная сборка через GitHub Actions. GitHub не требует и не хранит P12, ключей App Store Connect или профилей подписи. Проверяй успешную компиляцию, unit-тесты и работу на устройстве прежде чем считать 1.4.0 стабильной.

## Изменения 1.4.1 (build 7)

- В разделе «Регламент» в режиме списка появилась сортировка: «Сначала ближайшие», «По календарному сроку» и «По добавлению». Сортировка не изменяет сами записи и запоминается между запусками.
- При смешении критериев пробега, календаря и моточасов режим «Сначала ближайшие» учитывает просрочку, приближение срока и использованную долю регламента. Без статистики движения невозможно достоверно вычислить календарную дату достижения пробега или моточасов.
- В настройках JSON-резервная копия и CSV-выгрузка разнесены по отдельным секциям. Восстановление принимает только JSON. CSV — это таблица для Excel/Google Sheets; его не нужно импортировать после полного восстановления JSON.
- Улучшены русские сообщения об ошибках выбора неправильного файла.

Проверенные данные 1.4.0 сохраняются, Bundle ID не меняется. Перед установкой сделай новую резервную копию JSON на iPhone.
