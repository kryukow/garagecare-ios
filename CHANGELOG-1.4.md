# GarageCare 1.4.0 (build 6)

Предварительная версия для проверки, не заменяющая рабочую 1.3.0 до успешных сборки и тестирования.

- Моточасы и срок регламентов по моточасам, предупреждение и прогресс.
- Отдельные типы топлива, в том числе LPG/CNG. Смешанные интервалы не включаются в расход.
- Редактирование заправок, истории обслуживания, перечень запчастей, фото чеков.
- PDF-экспорт истории обслуживания с фотографиями чеков.
- HU/TÜV: типовая работа с настраиваемыми 24 месяцами.
- Более безопасное восстановление копий: проверка ссылок, идентификаторов и значений до замены данных, rollback при ошибках.
- JSON v3 с импортом старых v1/v2.
- Исходники без персональных ключей и сертификатов, сборка неподписанного IPA на GitHub.

Ограничения: существующим заправкам из старого архива автоматически присваивается «Бензин» — LPG необходимо поменять вручную. При частом чередовании топлива расход рассчитан только для однородной последовательности заправок. До удаления 1.3.0 необходима проверка всех записей после импорта.
